ABOUT THE JOB
This internship is for students who want hands-on experience building real backend systems.

Auto Wisdom emphasizes production engineering, responsibility, practical learning, and direct feedback. Interns work with the founder and get exposure to backend engineering, software architecture, product decisions, and operating production systems.

The role involves working on APIs, data flows, and backend systems used by real users, not isolated practice projects.

ABOUT AUTO WISDOM
Auto Wisdom builds automotive intelligence and digital products that help people make better decisions about cars, car ownership, and automotive services.

The company is founder-led, so the intern will have direct exposure to engineering decisions and the practical challenges of building and maintaining production software.

Company size: 1–10 employees

WHY JOIN
- Build and release production backend features using Go and PostgreSQL.
- Work directly with the founder on engineering and architecture decisions.
- Receive frequent technical and product feedback.
- Work on APIs, authentication, data models, background jobs, and production workflows.
- Understand how backend, frontend, infrastructure, and product decisions connect.
- Take responsibility for work from understanding requirements through implementation, review, quality assurance, and release.
- Gain practical experience maintaining an existing production codebase.

RESPONSIBILITIES
1. Build and maintain backend services using Go (Golang).
2. Design and evolve REST APIs and their request/response contracts.
3. Work with PostgreSQL, relational data modelling, database migrations, and queries.
4. Develop reliable background jobs and asynchronous workflows.
5. Use Redis for caching, coordination, and temporary state where necessary.
6. Implement authentication, authorization, and secure account workflows.
7. Handle database transactions, retries, idempotency, and failure recovery.
8. Debug frontend-backend integration and production issues.
9. Write tests for successful operations, failure scenarios, and important edge cases.
10. Review existing architecture before introducing new services or patterns.
11. Participate in code reviews and architecture discussions.
12. Use Docker and existing deployment and continuous integration workflows.
13. Document important APIs, engineering decisions, and implementation trade-offs.

HOW THEY EXPECT YOU TO WORK
Auto Wisdom emphasizes problem-solving and engineering judgment, not just code that happens to work.

Interns are expected to:
- Understand requirements, existing code, and data flows before implementing changes.
- Research unfamiliar concepts before choosing an approach.
- Break complicated tasks into clear implementation plans.
- Identify dependencies, assumptions, risks, and edge cases early.
- Investigate problems independently and ask focused questions when blocked.
- Avoid repeatedly trying fixes without understanding the underlying cause.
- Estimate tasks realistically and improve estimation over time.
- Meet agreed deadlines and communicate delays before deadlines pass.
- Provide revised completion estimates when timelines change.
- Test and review their own changes before requesting code review.
- Consider security, concurrency, data integrity, failure recovery, and backward compatibility.
- Take ownership of tasks through implementation, review, quality assurance, and completion.
